# Скрипты разбора адресных программ

Здесь лежит логика, которой пользуется ассистент, когда вы присылаете ему
адресную программу. В интерфейсе системы импорта нет — файл приходит в чат,
разбирается этими парсерами и раскладывается по базе через подключение к Supabase.

- `ap-parser.ts` — разбор адресной программы. Колонки ищутся по названиям
  заголовков, а не по буквам: между листами одной АП они съезжают. Понимает
  «Статус конструкций» (`Готовы к размещению` / `Занято с … по …` / `Занято до …`),
  «Слот», «Зона расположения», «Тип конструкции» (шкафчики или зеркала).
- `clubs-parser.ts` — разбор справочника «клуб + менеджер + сеть» с жёсткими
  проверками: дубликаты, потерянные строки, контрольное количество клубов.

Куда что попадает после разбора:

| Из АП | Куда |
| --- | --- |
| клуб, сеть | `lockers_clubs` (создаётся или дополняется) |
| слот + раздевалка + период занятости | `lockers_slot_status`, `source = 'ap'` |
| клиент и период РК | `lockers_campaigns` + `lockers_placements` |

Ручные статусы (`source = 'manual'`) при разборе не затираются.
